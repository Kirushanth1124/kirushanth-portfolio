# Kirushanth Portfolio

A responsive personal portfolio for Kirushanth, Intern Software Engineer.

## Run locally
Open `index.html` in your browser, or use any static server.

## Deploy
This folder can be deployed directly to Vercel, Netlify, GitHub Pages, or any static web host.

## Main sections
- Hero
- About
- Experience
- Featured project: AgriTamizha
- Skills
- Education
- Services
- Contact

Default theme is dark. Light mode can be toggled from the navigation bar.
